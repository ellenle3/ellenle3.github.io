ifugen

The repository comprises a set of sequential and non-sequential Zemax DLLs that were primarily designed to model image slicer integral field units, but can be used to describe a nearly arbitrary regular grid of surfaces.

Repository

ichigo

ichigo is a python package for scripting observations with Mark Chun’s RTC. The repository is currently private as it calls legacy scripts that contain sensitive information. If you are working with ‘imaka, please see the documentation below.

elgyem

I developed a package that trains a neural network to verify the orientation of orbiting Mars samples as part of the Mars Sample Return mission at NASA GSFC. This package cannot be made available to the public, but my results are shown at the end of this paper:

  • Bos, Brent J., et al., including Lee, E., 2024, “Vision System for the Mars Sample Return Capture Containment and Return System (CCRS),” Aerospace
