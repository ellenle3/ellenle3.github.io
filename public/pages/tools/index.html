ifugen

The repository comprises a set of sequential and non-sequential Zemax DLLs that were primarily designed to model image slicer integral field units, but can be used to describe a nearly arbitrary regular grid of surfaces. I have been able to reproduce the design of IRTF’s facility spectrograph SPECTRE, which has a 36-slice Winlight image slicer. I will release the source code after my paper is published…

ichigo

ichigo is a python package for scripting observations with our RTC. The RTC was written in C by Mark Chun and was developed for use with ‘imaka, a GLAO demonstrator for the UH88 telescope. We have used this RTC to test the IRTF ASM as well. ichigo executes commands over SSH to automate data storage, retrieval, and processing, which allows us to script common observing tasks (e.g., generating AO calibrations).

elgyem

I worked at NASA GSFC for a summer on the Mars Sample Return mission. I developed a package that trains a neural network to verify the orientation of the orbiting Mars samples. This package isn’t available to the public, but the results are published at the end of this paper:

  • Bos, Brent J., et al. “Vision System for the Mars Sample Return Capture Containment and Return System (CCRS).” Aerospace 11.6 (2024): 456.
